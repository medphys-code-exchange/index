# License Policy

- Any **OSI-approved** license is accepted. A `LICENSE` file is a hard
  requirement at every tier.
- The license is **first-class index metadata**, displayed on the badge/entry
  before anyone downloads anything.
- **Recommendation for new code: Apache-2.0.** Its explicit patent grant
  matters in medical software; MIT is acceptable, Apache-2.0 is better.
- **Copyleft (GPL/AGPL) is accepted but flagged** visibly on the index entry.
  Rationale: hospital legal review frequently blocks copyleft adoption;
  users must see it before integrating, not discover it after.
- Relicensing is never required — authors own their repos (hybrid
  architecture). The frozen fork carries the license as reviewed.
- Mixed-license submissions (vendored third-party code) must document every
  component license in the README; the index entry shows the primary license
  plus a "contains mixed licenses" flag.
