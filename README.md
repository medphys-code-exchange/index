# Medical Physics Community Code Exchange

A curated, peer-reviewed index of open-source software for radiation oncology
and medical physics. Authors keep their repositories; accepted tools get a
citation and a frozen, badged snapshot pinned to the exact reviewed commit.
Review is open and public. New here? See [CONTRIBUTING.md](CONTRIBUTING.md).

**Tiers:** Tier 1 (research, light bar) · Tier 2 (rigorous: tests, CI, docs,
DOI) · Tier C (clinical-adjacent: Tier 2 + validation dataset + commissioning
checklist). Full requirements in [docs/tiers.md](docs/tiers.md).

## Submit a tool

Open a **Tool Submission** issue using the
[intake form](.github/ISSUE_TEMPLATE/submission.yml) and read
[CONTRIBUTING.md](CONTRIBUTING.md) first. You post a DCO attestation covering
the reviewed commit and sign new commits going forward (existing history does
not need signing), and the PHI and vendor-binary scanners must pass.
